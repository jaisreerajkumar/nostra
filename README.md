# 🛍️ Nostra - E-commerce Website

A **responsive e-commerce website** built using **HTML, CSS, and JavaScript**.  
This project includes a Home page, Collections page, and Contact Us page — with **search** and **filter** functionality implemented using JavaScript.

---

## 🚀 Features

### 🏠 Home Page (`index.html`)
- Introduction to the Nostra e-commerce platform  
- Responsive navigation bar  
- Featured collections or promotional sections  
- Footer with contact and social media links  

### 🛒 Collections Page (`collections.html`)
- Displays all product collections  
- **Search bar** for finding products by name or keyword  
- **Filter functionality** (e.g., by category, price, or availability)  
- Responsive product grid layout  

### ✉️ Contact Us Page (`contact.html`)
- Contact form (name, email, message)  
- Validation using HTML/CSS  
- Business contact details  

---

## 🧠 Functional Requirements

| Functionality | Description |
|----------------|-------------|
| 🔍 **Search** | Search for products dynamically on the Collections page using JavaScript |
| 🧩 **Filter** | Filter products (e.g., by category, brand, or price range) dynamically using JavaScript |
| 💻 **Responsive Design** | Fully responsive layout for desktop, tablet, and mobile views |
